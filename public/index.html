Manage RSS Feeds & Import Inoreader OPML

Import from Inoreader (OPML)

Export your subscriptions from Inoreader (Preferences → Import/Export → Export OPML) and upload the .opml or .xml file here. Feeds will be automatically assigned to World, Climate, Tech, Science, or Singapore.

Gemini API & Ranking Settings

Pulse uses the Gemini Interactions API (gemini-3.8-flash) with structured JSON schemas to summarize articles, compute personalized relevance scores within each category, and synthesize your dynamic persona.

Cross-Device Sync (PC ↔ Mobile on GitHub Pages)
To automatically sync your Evolving Persona and Added RSS Feeds between your PC and Mobile without manual git commits, enter your GitHub repo (e.g. HaoWei07/pulse-rss-reader) and a GitHub Personal Access Token (with Contents: Read & Write permission).
